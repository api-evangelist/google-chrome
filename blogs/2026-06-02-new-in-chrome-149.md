Chrome 149 introduces CSS gap decorations for styling gaps between grid and flex items, improved WebSocket disconnection handling for the back/forward cache (bfcache), and expanded internationalization options through Intl.Locale variants. These additions improve layout flexibility, page navigation performance, and locale-aware formatting for web developers.
