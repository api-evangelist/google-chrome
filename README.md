## Google Chrome on APIs.io

Everything profiled for Google Chrome is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/google-chrome/](https://apis.io/providers/google-chrome/)** — or go straight to one of the APIs or properties below.

### APIs (15)

- [Chrome Extensions API](https://apis.io/apis/google-chrome/chrome-extensions-api/) — APIs for building Chrome browser extensions.
- [Chrome DevTools Protocol](https://apis.io/apis/google-chrome/chrome-devtools-protocol/) — Instrument, inspect, debug and profile Chromium, Chrome and other Blink-based browsers.
- [Chrome Web Store API](https://apis.io/apis/google-chrome/chrome-web-store-api/) — API for publishing and managing extensions in the Chrome Web Store.
- [Chrome User Experience Report API](https://apis.io/apis/google-chrome/chrome-user-experience-report-api/) — Access real-world user experience data for popular websites.
- [Chrome Policy API](https://apis.io/apis/google-chrome/chrome-policy-api/) — API for programmatically viewing and managing Chrome policies assigned to Organizational Units.
- [Chrome Verified Access API](https://apis.io/apis/google-chrome/chrome-verified-access-api/) — API to cryptographically verify that ChromeOS clients are genuine and conform to corporate policy.
- [Google Safe Browsing API](https://apis.io/apis/google-chrome/google-safe-browsing-api/) — API to check URLs against Google lists of unsafe web resources including phishing and malware sites.
- [PageSpeed Insights API](https://apis.io/apis/google-chrome/pagespeed-insights-api/) — API to measure web page performance and receive optimization suggestions using Lighthouse and CrUX data.
- [Chrome Built-in AI APIs](https://apis.io/apis/google-chrome/chrome-built-in-ai-apis/) — On-device AI APIs powered by Gemini Nano built into Chrome for text generation, summarization, translation, and more.
- [Google Chrome App Details API](https://apis.io/apis/google-chrome/google-chrome-app-details-api/) — Operations for retrieving information about Chrome apps, extensions, and Android apps available to managed devices.
- [Google Chrome Reports API](https://apis.io/apis/google-chrome/google-chrome-reports-api/) — Operations for generating reports about browsers, devices, installed apps, extensions, and app usage within the enterprise.
- [Google Chrome Telemetry Devices API](https://apis.io/apis/google-chrome/google-chrome-telemetry-devices-api/) — Operations for retrieving telemetry data from managed ChromeOS devices including hardware specs, OS version, CPU, memory, storage, and network information.
- [Google Chrome Telemetry Events API](https://apis.io/apis/google-chrome/google-chrome-telemetry-events-api/) — Operations for listing telemetry events from managed ChromeOS devices such as USB peripherals, audio, network state changes, and hardware status events.
- [Google Chrome Telemetry Notification Configs API](https://apis.io/apis/google-chrome/google-chrome-telemetry-notification-configs-api/) — Operations for managing telemetry notification configurations that enable push notifications for telemetry events.
- [Google Chrome Telemetry Users API](https://apis.io/apis/google-chrome/google-chrome-telemetry-users-api/) — Operations for retrieving telemetry information associated with managed users on ChromeOS devices.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Google Chrome: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
